# Annin Robotics Downloads

Archive of AR2/AR3/AR4 software, firmware, 3D print files, manuals and other downloads formerly hosted on anninrobotics.com (WordPress `wp-content/uploads`).

- Files under 50 MB are in this repo, organized by original upload path (`YYYY/MM/filename`).
- Larger files (HMI executable bundles and similar) are attached to the [`files-v1` release](../../releases/tag/files-v1).
